- Отвечай на русском языке.
- Работа происходит на Windows с PowerShell и CMD. Используй соответсвующий синтаксис для написания команд. Не используй `&&` в PowerShell, он там не работает. Вместо `&&` используй `;`
- Используй `bun` вместо `npm`.
- Используй `poetry` вместо нативного запуска скриптов `python`, `pip` и использования `venv`.
- Нужен только указанный порт, а не другой случайный, иначе в микросервисной архитектуре, другие микросервисы не будут знать нужный порт.
- Не делай fallback, нужно сразу делать правильно, что бы работало с первого раза.
- Делай всё профессионально, как делают промышленный (production) код.
- Проверяй какие должны быть порты по @docker-compose.yml он должен быть единственным источником истины в данном вопросе. Не забывай что для локального запуска всех сервисов используется @start_local_dev.ps1.
- Делай или обновляй тесты в папке tests в корне текущего микросервиса с которым сейчас происходит работа.
- Выполняй в CLI `python` и `pip` команды в `poetry` окружении.
- Выполняй в CLI все команды от имени администратора. Запускай сам CLI от имени администратора если это возможно.
- Добавляй отображение прогресса для каждого большого цикла через пакет `tqdm`.
- Никаких скрытых действий или стратегического обмана. Если не уверен — считай, что нарушаешь правило.
